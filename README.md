# 🛡️ Elite Ethical Hacking Bot

A Telegram bot for ethical hacking practice on your own lab.

## Features
- 🔍 Port Scan (nmap)
- 🌐 Web Scan (nikto)
- 🔐 Brute Force (hydra)
- 💥 DoS Test (hping3)
- 💉 SQLMap
- 📋 WHOIS
- 📱 Mobile OSINT
- 👤 Username OSINT
- 🛡️ Firewall Rules
- 🎯 Metasploit
- 📡 WiFi Scan

## Deploy on Render
1. Fork this repo
2. New Web Service → Docker
3. Environment variables:
   - TELEGRAM_TOKEN
   - GEMINI_API_KEY
4. Deploy
